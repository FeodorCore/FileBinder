# FileBinder
[🇷🇺 Русский](README.ru.md) | [🇬🇧 English](README.md)

Консольная утилита для объединения файлов проекта в один текстовый файл.

## Установка

```bash
pip install .
```

Требования: Python 3.10+, `typer==0.24.1`.

## Использование

```
filebinder [КОМАНДА] [ОПЦИИ]
```

## Команды

### `bind`
Собрать файлы в один выходной файл.

```
filebinder bind [ОПЦИИ]
```

Опции:
- `--ignore` / `-i` – Игнорировать файл исключений (правила игнорирования не применяются).
- `--hidden` / `-s` – Включать скрытые файлы и папки.
- `--nignore` / `-ni` ТЕКСТ – Пользовательское имя файла игнорирования (по умолчанию: `filebinderignore.txt`).
- `--nbinder` / `-nb` ТЕКСТ – Имя выходного файла-сборки (по умолчанию: `filebinder.txt`).

### `read`
Вывести список файлов, которые будут включены (без реальной записи).

```
filebinder read [ОПЦИИ]
```

Опции:
- `--ignore` / `-i`
- `--hidden` / `-s`
- `--nignore` / `-ni` ТЕКСТ

### `info`
Показать информацию о версии, авторе и описании программы.

## Файл игнорирования (`filebinderignore.txt`)
Обычный текстовый файл, каждая строка — относительный путь к файлу или префикс директории. У конечных директорий слеш можно не ставить. Пустые строки пропускаются.

Пример:
```
.git/
node_modules/
temp.txt
dist/main.js
```

- Замыкающие слеши автоматически удаляются.
- Логика совпадений: точное совпадение относительного пути **или** путь файла начинается с указанного префикса директории.

## Формат вывода
Файл-сборка (по умолчанию `filebinder.txt`) содержит:

```
-----relative/path/to/file.ext-----

<содержимое файла>

-----another/file.ext-----

<содержимое файла>
```

В терминал выводится отчёт о статусе:
- ✓ файл записан / прочитан успешно
- ✗ файл не найден / ошибка доступа / ошибка декодирования

## Примечания
- Всегда работает в текущей рабочей директории.
- Выходной файл и сам файл игнорирования никогда не включаются в сборку.
- Ошибки декодирования Unicode пропускаются и отмечаются в отчёте.
